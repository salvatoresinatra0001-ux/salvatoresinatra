# Salvatore Sinatra — Website Identity V1.0

## Scopo
Landing editoriale personale e professionale per https://www.salvatoresinatra.it/.
Fotografia fine art, editoriale, ritratto, ricerca visiva e interessi di studio.

## File
- index.html — landing responsive in italiano
- assets/site.css — design system monocromatico
- assets/site.js — navigazione accessibile su mobile
- assets/photos/ — sette fotografie già presenti nel repository, non modificate
- favicon.svg — monogramma SS
- privacy.html — informativa descrittiva, da verificare con la configurazione di produzione
- robots.txt, sitemap.xml — SEO
- netlify.toml — pubblicazione statica dalla root, intestazioni di sicurezza

## Deploy Netlify
Progetto già creato: salvatoresinatra-production.
Collegare manualmente GitHub repo salvatoresinatra0001-ux/salvatoresinatra;
branch main solo dopo approvazione e merge della pull request.
Build command: nessuno. Publish directory: ".".

## Controlli prima del merge
1. Verificare autenticità, diritti e corrispondenza dei sette asset fotografici.
2. Confermare contenuti curriculari e descrizioni delle serie.
3. Verificare link professionali, privacy, metadati e accessibilità.
4. Confermare collegamento Git e primo deploy di anteprima.
5. Controllare DNS attuali prima di associare dominio e redirect www/apex.
6. Verificare HTTPS e sitemap soltanto dopo la pubblicazione.

## Vincoli
Non introdurre immagini sintetiche, dati sanitari o titoli accademici non conseguiti.
Non modificare Atlas Preview, DNS, servizi email o altri domini.
